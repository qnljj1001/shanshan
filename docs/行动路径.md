# 行动路径

## 总原则

先跑通主链路，再补工程化。

优先级：

```text
模型调用
  -> 后端接口
  -> 前端页面
  -> 文档解析
  -> RAG 检索
  -> 评估优化
  -> Agent 工具
  -> Docker 部署
  -> 面试包装
```

不要第一步写 Docker。Docker 用来打包已经能跑的应用，不用来替代本地开发。
