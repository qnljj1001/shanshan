# 开发指南

## 1. 开发环境

推荐环境：

```text
Windows 11
  + WSL Ubuntu
  + VS Code / Cursor
  + Git
  + Python 3.11+
  + Node.js 20+
  + Docker Desktop
```

代码建议放在 WSL 的 Linux 文件系统中，例如：

```bash
cd ~
mkdir ai-doc-assistant
cd ai-doc-assistant
```

不要把主要项目代码放在 `/mnt/c/...` 下，否则依赖安装和文件监听可能变慢。

---

## 2. 后端初始化

计划命令：

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install fastapi uvicorn openai python-dotenv pydantic
pip freeze > requirements.txt
```

启动命令：

```bash
uvicorn app.main:app --reload --port 8000
```

访问：

```text
http://127.0.0.1:8000/docs
```

---

## 3. 前端初始化

计划命令：

```bash
cd frontend
npm create vite@latest . -- --template vue-ts
npm install
npm run dev
```

访问：

```text
http://127.0.0.1:5173
```

---

## 4. 环境变量

从 `.env.example` 复制 `.env`：

```bash
cp .env.example .env
```

必须配置：

```text
OPENAI_BASE_URL
OPENAI_API_KEY
MODEL_NAME
EMBEDDING_MODEL_NAME
```

注意：

- `.env` 不能提交到 Git。
- `.env.example` 可以提交，用来说明需要哪些配置。

---

## 5. Git 工作流

推荐 commit 类型：

```text
feat: 新功能
fix: 修复问题
docs: 文档变更
refactor: 重构
test: 测试
chore: 工程配置
```

例子：

```bash
git add .
git commit -m "feat: add basic chat api"
```

阶段 tag：

```bash
git tag v0.1-api
git tag v0.2-chat
git tag v0.3-rag
git tag v0.4-evaluation
git tag v0.5-agent-tools
git tag v0.6-deploy
```

## 6. AI 工具分工

### Cursor

适合：

- 日常编码。
- 写前端组件。
- 小范围修改。
- 类型补全。

### Codex / Claude Code / clawcode

适合：

- 读仓库。
- Debug。
- 重构。
- 写测试。
- 排查 Docker 问题。

### ChatGPT / Claude / hermes

适合：

- 学习解释。
- 技术选型讨论。
- Prompt 设计。
- 面试模拟。

### Workbuddy

适合：

- 整理文档。
- 生成日报周报。
- 梳理面试材料。

---

## 7. 每次开发前检查

```bash
pwd
git status
```

确认：

- 当前目录正确。
- 没有误改无关文件。
- 当前分支清楚。

---

## 8. 每次开发后检查

至少做：

```bash
git status
```

后端阶段：

```bash
uvicorn app.main:app --reload --port 8000
```

前端阶段：

```bash
npm run dev
```

Docker 阶段：

```bash
docker compose up --build
```
