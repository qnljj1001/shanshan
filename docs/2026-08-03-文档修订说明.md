## 4. 关于 `uvicorn app.main:app` 路径

文档中所有启动命令保留统一使用 `uvicorn app.main:app`（基于"未来结构" `backend/app/main.py`）。但本人在第一次修改时误把 import path 改成了 `uvicorn main:app`（基于"当前结构" `backend/main.py`），用户已手动改回。

**当前结论**：
- 一旦 `backend/main.py` 迁移到 `backend/app/main.py`，统一用 `uvicorn app.main:app`
- 如果用户当前仍在 `backend/main.py` 旧结构，临时用 `uvicorn main:app`

> 截至 2026-08-03 18:09，git status 显示 `backend/main.py` 已 deleted、`backend/app/` 已创建，说明迁移已完成。文档使用 `app.main:app` 是对的。
