# 数据模型

第一阶段可以使用 SQLite。后续部署或面试展示时可以迁移到 MySQL。

---

## 1. sessions

保存聊天会话。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 会话 ID |
| title | string | 会话标题 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

索引：

- `idx_sessions_updated_at`

---

## 2. messages

保存聊天消息。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 消息 ID |
| session_id | string | 会话 ID |
| role | string | `user` / `assistant` / `system` |
| content | text | 消息内容 |
| model | string | 使用的模型 |
| token_usage | json | token 使用情况 |
| created_at | datetime | 创建时间 |

索引：

- `idx_messages_session_id_created_at`

---

## 3. documents

保存文档元数据。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 文档 ID |
| filename | string | 原始文件名 |
| file_type | string | pdf / docx / md / txt |
| file_path | string | 文件存储路径 |
| status | string | uploaded / parsed / indexed / failed |
| error_message | text | 失败原因 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

索引：

- `idx_documents_status`
- `idx_documents_created_at`

---

## 4. document_chunks

保存文档切片元数据。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | chunk ID |
| document_id | string | 文档 ID |
| chunk_index | integer | 第几个 chunk |
| content | text | chunk 文本 |
| content_hash | string | 文本 hash |
| token_count | integer | 估算 token 数 |
| metadata | json | 页码、标题等来源信息 |
| created_at | datetime | 创建时间 |

索引：

- `idx_chunks_document_id`
- `idx_chunks_content_hash`

说明：

向量本体第一阶段可以存 FAISS 文件中，数据库只保存 chunk 元数据和引用关系。

---

## 5. rag_queries

保存 RAG 问答记录，便于后续评估。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 查询 ID |
| question | text | 用户问题 |
| answer | text | 模型回答 |
| retrieved_chunks | json | 检索到的 chunk 列表 |
| top_k | integer | 检索数量 |
| model | string | 回答模型 |
| created_at | datetime | 创建时间 |

索引：

- `idx_rag_queries_created_at`

---

## 6. tool_runs

保存工具调用记录。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 调用 ID |
| tool_name | string | 工具名称 |
| input | json | 工具输入 |
| output | json | 工具输出 |
| status | string | success / failed |
| error_message | text | 错误信息 |
| started_at | datetime | 开始时间 |
| finished_at | datetime | 结束时间 |

索引：

- `idx_tool_runs_tool_name`
- `idx_tool_runs_started_at`

---

## 7. 第一阶段不做的表

第一阶段暂不做复杂用户系统。

可后续增加：

- users。
- roles。
- permissions。
- api_keys。
- audit_logs。

原因：

先完成单用户项目闭环，后续再扩展权限和审计。
