# RAG 评估文档

## 1. 评估目标

RAG 项目不能只证明“能回答”，还要证明：

1. 回答是否正确。
2. 引用是否准确。
3. 没有答案时是否拒答。
4. 参数调整是否真的带来效果提升。

---

## 2. 测试集设计

准备 30 到 50 条问题，分为四类：

| 类型 | 数量 | 目的 |
| --- | --- | --- |
| 事实型问题 | 10-15 | 测试能否找到明确答案 |
| 总结型问题 | 5-10 | 测试多片段综合能力 |
| 对比型问题 | 5-10 | 测试跨文档检索能力 |
| 无答案问题 | 5-10 | 测试拒答能力 |

---

## 4. 评估指标

### 4.1 回答正确性

评分：

| 分数 | 含义 |
| --- | --- |
| 2 | 回答正确且完整 |
| 1 | 回答部分正确 |
| 0 | 回答错误或无关 |

---

### 4.2 引用准确性

评分：

| 分数 | 含义 |
| --- | --- |
| 2 | 引用完全支持回答 |
| 1 | 引用部分支持回答 |
| 0 | 引用错误或缺失 |

---

### 4.3 拒答准确性

用于无答案问题。

评分：

| 分数 | 含义 |
| --- | --- |
| 1 | 正确拒答 |
| 0 | 编造答案 |

## 7. 优化方向

优先级从高到低：

1. 调整 chunk size。
2. 调整 overlap。
3. 调整 top_k。
4. 改进 Prompt。
5. 增加拒答判断。
6. 增加 rerank。
7. 增加关键词检索和向量检索混合策略。
