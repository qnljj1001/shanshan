# 开发指南

## 1. 开发环境

推荐环境：

```text
Windows 11
  + PyCharm（IDE，Python Interpreter 选 Conda 环境 fastapi-demo）
  + Git for Windows（git bash）
  + Conda 环境 fastapi-demo（Python 3.11+）
  + Node.js 20+
  + Docker Desktop
```

代码直接放在当前工作目录（Windows 文件系统），例如：

```text
D:\shanshan\ai-doc-assistant
```

PyCharm 设置（首次打开项目时）：

1. `File → Settings → Project: ai-doc-assistant → Python Interpreter`
2. 点齿轮 → `Add Interpreter → Conda Environment → Existing environment`
3. 选 `fastapi-demo`（路径类似 `C:\Users\OMen\miniconda3\envs\fastapi-demo\python.exe`）
4. PyCharm 会自动激活环境，无需手动 `conda activate`

---

## 2. 后端初始化

使用现有的 Conda 环境 `fastapi-demo`（PyCharm 已配好）：

```bash
# git bash / PowerShell / CMD 通用
conda activate fastapi-demo

# 进入 backend 并装依赖
cd backend
pip install -r requirements.txt
```

如果还没有 `fastapi-demo` 环境，新建一次：

```bash
conda create -n fastapi-demo python=3.11 -y
conda activate fastapi-demo
```

启动命令：

```bash
conda activate fastapi-demo
cd backend
uvicorn app.main:app --reload --port 8000
```

> PyCharm 用户：Python Interpreter 设好之后，直接点 Run 按钮即可，PyCharm 自动激活环境，命令行手动 `conda activate` 不是必需的。

访问：

```text
http://127.0.0.1:8000/docs
```

---

## 3. 前端初始化

计划命令：

```bash
cd frontend
npm create vite@latest . -- --template vue-ts
npm install
npm run dev
```

访问：

```text
http://127.0.0.1:5173
```

## 4. 环境变量

在 `backend/` 目录下创建 `.env`（可参考项目根目录的 `.env.example`）：

```bash
cd backend
cp ../.env.example .env
# 然后编辑 .env，填入 OPENAI_BASE_URL、OPENAI_API_KEY、MODEL_NAME
```

必须配置：

```text
OPENAI_BASE_URL
OPENAI_API_KEY
MODEL_NAME
EMBEDDING_MODEL_NAME
```

注意：

- `.env` 不能提交到 Git。
- `.env.example` 可以提交，用来说明需要哪些配置。

## 5. Git 工作流

推荐 commit 类型：

```text
feat: 新功能
fix: 修复问题
docs: 文档变更
refactor: 重构
test: 测试
chore: 工程配置
```

例子：

```bash
git add .
git commit -m "feat: add basic chat api"
```

阶段 tag：

```bash
git tag v0.1-api
git tag v0.2-chat
git tag v0.3-rag
git tag v0.4-evaluation
git tag v0.5-agent-tools
git tag v0.6-deploy
```
