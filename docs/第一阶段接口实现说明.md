# 第一阶段接口实现说明

这份文档用于指导第一个可运行版本。

---

## 1. 目标

先完成：

```text
FastAPI 后端
  -> 调用 OpenAI 兼容接口
  -> 返回模型回答
```

不做：

- 前端。
- 数据库。
- Docker。
- RAG。
- 用户系统。

---

## 2. 最小后端结构

```text
backend/
  app/
    services/
      llm.py
    main.py
  requirements.txt
```

---

## 3. 环境与依赖

使用 Conda 管理 Python 环境（环境名可自定义，推荐 `fastapi-demo`）：

```bash
# 首次创建（只需一次；若已有 fastapi-demo 可跳过）
conda create -n fastapi-demo python=3.11 -y
conda activate fastapi-demo

cd backend
pip install -r requirements.txt
```

依赖列表见 `backend/requirements.txt`，核心包：

```text
fastapi、uvicorn、openai、python-dotenv、pydantic
```

---

## 4. 第一个接口

### POST `/api/chat`

请求：

```json
{
  "message": "你好，请用一句话介绍你自己"
}
```

响应：

```json
{
  "answer": "你好，我是一个可以帮助你处理文档和回答问题的 AI 助手。"
}
```

---

## 5. 测试命令

启动后端：

```bash
conda activate fastapi-demo   # 换成你的 Conda 环境名
cd backend
uvicorn app.main:app --reload --port 8000
```

测试健康检查：

```bash
curl http://127.0.0.1:8000/api/health
```

测试聊天：

```bash
curl -X POST http://127.0.0.1:8000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"请用一句话解释 RAG"}'
```

---

## 6. 完成标准

第一阶段完成时，应满足：

- `/api/health` 返回正常。
- `/api/chat` 能返回模型回答。
- 模型配置通过 `.env` 读取。
- API key 没有写死在代码里。
- README 已记录启动方式。
